# Dark YouTube Retention Editor

Skill portável para agentes de IA com suporte a instruções no formato `SKILL.md`.

## Instalação
1. Extraia o ZIP.
2. Copie a pasta `dark-youtube-retention-editor` para o diretório de Skills do seu agente, se o runtime oferecer esse recurso.
3. Garanta que o agente tenha acesso a ferramentas reais de inspeção e edição/renderização de vídeo (por exemplo, FFmpeg e/ou um editor baseado em timeline).
4. Ative/carregue a Skill no agente.

## Importante
O DeepSeek, por si só, é o modelo de linguagem. A capacidade de editar e exportar vídeo depende do aplicativo/agente que o envolve e das ferramentas que ele disponibiliza. A Skill define o comportamento e o fluxo de trabalho; ela não instala um editor de vídeo nem concede acesso automático a FFmpeg, transcrição, geração de imagens ou renderização.

## Regra central
Efeitos criativos somente entre 00:00 e 02:00. O vídeo completo deve ser exportado, preservando áudio, duração e todo o trecho posterior a 02:00.
